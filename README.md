# LunaQuest Junior — Moon Settlement Mission Game

An interactive browser game created for NASA Space Apps Challenge Lira 2026. Players manage a four-person crew over a 14-day lunar settlement mission, balance resources, construct systems and research upgrades.

## Run locally
Open `index.html` in a modern browser. No npm installation, build step, account, API key, or network connection is required for the game itself. Optional source-reference links open NASA websites when online.

## Deploy to GitHub Pages
1. Create a public repository on GitHub.
2. Upload `index.html`, `styles.css`, `app.js`, and the entire `assets/` folder **to the repository root**.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Select **main**, folder **/(root)**, and Save.
5. Open the site URL GitHub Pages gives you once deployment completes.

Other static hosts (Netlify, Vercel, Cloudflare Pages) also work with the same folder.

## Features
- Opening screen and two strategic landing region scenarios
- Mission resource controls; 14-day survival challenge; research, operations and construction
- Semi-random deterministic events, objective tracking, results and replay
- Browser save/resume through localStorage; optional user-controlled sound
- Lunar physics weight calculator and links to official NASA science and planetary data sources
- Responsive layout and original lunar panorama asset

## Science and provenance
Basic Moon constants used by the game are drawn from NASA's public lunar facts references: gravity approximately 1.62 m/s², average radius approximately 1,737.4 km, and a synodic lunar phase period approximately 29.53 Earth days. NASA resource links are accessible in-game.

Solar scenarios, life-support economy, landing-region parameters, incidents, engineering upgrade effects, and rover yields are **fictional gameplay models**. The game does not claim to ingest a live NASA lunar dataset or produce lunar-engineering forecasts. For a research-grade NASA challenge submission, validate gameplay assumptions against mission datasets and requirements.
